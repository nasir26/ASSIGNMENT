# Academic Assignments — Quantum Computing

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Collection of quantum computing and physics assignments completed during MSc Physics
at Jawaharlal Nehru University (JNU), New Delhi.

**Author**: Nasir Ali — Centre for Development of Advanced Computing (C-DAC), Noida

## Contents

| Folder | Topic |
|--------|-------|
| `quantum_circuits/` | Qiskit circuit assignments |
| `quantum_mechanics/` | Analytical problem sets |
| `numerical_methods/` | Computational physics exercises |

## Tools Used

- Python 3.10, Qiskit, NumPy, SciPy, Matplotlib
- IBM Quantum Experience (simulators + real hardware)

## Note

These are educational assignments for personal reference. Some solutions may be simplified
for clarity over production correctness.
